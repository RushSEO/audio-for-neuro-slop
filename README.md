# article-audio

Озвучка статей для статичного Astro-сайта: скрипт превращает текст в mp3 с точными таймингами предложений, компонент `AudioPlayer.astro` встраивает плеер в страницу.

## Запуск

```bash
npm install
pip install num2words espeakng-loader      # + piper-tts, если нужен локальный нейроголос
npm run prepare -- shredder                # data-src -> src/data/articles/shredder.json
npm run audio -- shredder                  # -> public/audio/shredder.mp3 + src/data/audio/shredder.json
npm run dev                                # http://localhost:4321/shredder/
```

Новая статья из Википедии: `npm run fetch -- "<url>" <slug> --words 1000`, затем `prepare` и `audio`.

## Голос

Движок выбирается переменной `TTS_ENGINE`, ключи только из окружения:

| TTS_ENGINE | Что нужно | Комментарий |
|---|---|---|
| `elevenlabs` | `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID` | лучшее качество; соседние предложения передаются для интонации |
| `openai` | `OPENAI_API_KEY`, опц. `OPENAI_TTS_VOICE` | gpt-4o-mini-tts, интонация задаётся промптом |
| `google` | `GOOGLE_TTS_API_KEY`, опц. `GOOGLE_TTS_VOICE` | Chirp 3 HD, по умолчанию `ru-RU-Chirp3-HD-Charon` |
| `piper` | `PIPER_MODEL=…/ru_RU-dmitri-medium.onnx` | бесплатно и локально, голоса rhasspy/piper-voices |
| `espeak` | ничего | робот, только для проверки механики |

Пример: `TTS_ENGINE=piper PIPER_MODEL=~/voices/ru_RU-dmitri-medium.onnx npm run audio -- shredder`.

## Как устроено

- `scripts/prepare_article.py` режет текст на предложения, у каждого `text` (на странице) и `speak` (для голоса). `speak` проходит через `data-src/lexicon.ru.json` (произношение латиницы, аббревиатур, «#32») и склонение чисел («в 2009 году» → «в две тысячи девятом году»).
- `scripts/tts.py` озвучивает по предложению, кэширует каждое в `.audio-cache/` по хешу текста и голоса, задаёт паузы сам (между предложениями, абзацами, перед заголовками), выравнивает громкость (−18 LUFS) и кодирует mp3 64 kbps моно. Тайминги каждого предложения и начала глав пишутся в `src/data/audio/<slug>.json`. Правка одного предложения переозвучивает только его.
- `src/components/AudioPlayer.astro`: скорость 0.75–2×, ±15 с, полоса с метками глав, список глав, подсветка звучащего предложения и переход кликом, мини-плеер снизу, Media Session (экран блокировки, наушники), запоминание позиции и скорости. Аудио не грузится до нажатия Play.
- Тайм-коды: полоса прогресса разбита на главы, при наведении подсказка «2:15 · глава»; оглавление с началом и длительностью каждой главы; у заголовков в тексте кнопка «▶ 1:04»; кнопки и клавиши N / P — следующая и предыдущая глава; «Ссылка на этот момент» копирует адрес `…/#t-125`. Плеер понимает и `#t=125`, `#t=2:05`, `#t=2m5s`, `?t=125`.
- В JSON-LD статьи добавляется `AudioObject`.
